Sensor Layout Studio - Windows x64 portable edition

Extract the entire ZIP, then run sensor-layout-studio.exe.
No application installer or Rust/Node.js development tools are required.
Microsoft Edge WebView2 Runtime is required. If it is unavailable, use the
setup edition, which installs the runtime as needed (Internet required).

This build is unsigned. Windows may display a publisher warning.
Save your scene as JSON before closing. Imported models must be selected
again when reopening a saved scene; keep the original model files.

Quick start: select front_camera or roof_lidar, drag the move/rotate gizmos,
adjust the field of view/range, and select Common to inspect shared coverage.
Purple = visible to every selected sensor. Red hatching = per-sensor blind spot.
